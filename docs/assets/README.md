# README brand assets

These assets reuse the public Mineral / jade identity.

- `../../spanshot-logo.svg`: exact copy of
  `https://www.spanshot.com/brand/spanshot-mark.svg`.
- `spanshot-mark-inverse.svg`: exact copy of
  `https://www.spanshot.com/brand/spanshot-mark-inverse.svg`.

The README uses the jade mark on light surfaces and the canonical light inverse
on dark surfaces through a `<picture>` element. Keep the geometry and colors of
the canonical exports. Inspect the README at desktop and mobile widths in both
themes when updating these assets.
